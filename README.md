# SprintDeck — Kanban Sprint Board & Issue Workspace

A Linear-inspired agile sprint workspace with HTML5 drag-and-drop columns, board/list views, filtering, story-point tracking, and `localStorage` persistence.

## Features
- 4-column Kanban board (*Backlog*, *In Progress*, *In Review*, *Done*) with native drag-and-drop and click-to-edit drawer
- Live story-point sprint velocity bar
- Multi-criteria filtering by search query, priority level, and category tag
- Full CRUD issue creation, editing, status transition, and deletion persisted in `localStorage`
